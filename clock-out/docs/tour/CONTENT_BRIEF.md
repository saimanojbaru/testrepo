# Floor Tour: content brief (starter set, author's own)

Status: **not built.** Sequenced after the phone gate clears. `settings.tourMode` is reserved.
The author writes or reviews the observation list before any build. The feature is a
container; this file is what fills it.

Rule for every entry: **deadpan, specific, observed. Not written as jokes. No punchlines.**
The comedy comes from recognition.
